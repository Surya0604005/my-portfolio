# Surya Teja Katta — Premium Portfolio

A cinematic, responsive React portfolio for Surya Teja Katta.

## Design direction

- Dark editorial / cinematic visual system
- Amber accent with subtle violet and emerald ambient light
- `✦ STK.°` personal monogram
- Hero headline: **CRAFTING / DIGITAL / EXPERIENCES**
- Responsive desktop, tablet and mobile layouts
- Project cards use cinematic project artwork instead of icon placeholders
- Currently Exploring section retained

## Run locally

```bash
npm install
npm run dev
```
