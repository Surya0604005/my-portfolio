## ⚙️ Run Locally

Want to explore or run the portfolio on your computer?

**1. Clone the repository**

```bash
git clone https://github.com/Surya0604005/my-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd my-portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Create a production build**

```bash
npm run build
```

## 🌐 Deployment

The portfolio is deployed using **Vercel** and connected to GitHub for source control.

To deploy your own copy:

1. Fork or clone this repository.
2. Import it into Vercel.
3. Configure the build command as `npm run build`.
4. Set the output directory to `dist`.
5. Deploy your application.
